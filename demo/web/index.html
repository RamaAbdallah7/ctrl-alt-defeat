Ten specialist project-management agents that live in the channel your team already argues about schedules in. Ask in plain language — a router wakes only the specialists the question needs, deterministic engines do every calculation, and one brief comes back for a human to decide on.

Open the live console View the code No sign-in. Everything computes in your browser.

How it works

Step 1

AskIn Slack or Microsoft Teams — a question, pasted figures, or a dropped CSV.

Step 2

RouteAn LLM picks which specialists apply and extracts their inputs. It never does the arithmetic.

Step 3

ComputeDeterministic Python engines run the real PM math, validated against known-correct answers.

Step 4

DecideOne consolidated brief, with Approve / Discuss / Reject. Every step is logged.

The math is checked, not trusted

The language model chooses which analysis to run and pulls the numbers out of a sentence. It never computes one. Every engine is pinned by tests to a published worked answer, so a wrong figure fails the build rather than reaching a brief.

Run it yourself

git clone https://github.com/RamaAbdallah7/ctrl-alt-defeat.git
cd ctrl-alt-defeat
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

.venv/bin/python -m pytest tests/ -q     # the full suite
.venv/bin/python demo/cli_demo.py all    # a brief, no API key needed

Chat surfaces: Slack setup (about 10 minutes, no public URL) · Microsoft Teams setup (needs an HTTPS endpoint, or the Bot Framework Emulator).
